# Northwind Stays 1.1.0 Release Notes

**Release:** 1.1.0
**Previous release:** 1.0.0
**Type:** Minor feature release

Northwind Stays 1.1.0 makes it easier for guests to find flexible stays. This release adds a Free cancellation filter and badge, and includes performance work behind the scenes.

## What's new

### Free cancellation filter

Guests can now limit their search results to properties that offer free cancellation.

- On the search results page, the filter panel has a new **Cancellation** section with a **Free cancellation** checkbox.
- Tick **Free cancellation** and click **Apply filters** to show only properties that offer free cancellation.
- The new filter works together with the existing price, star rating, property type and amenity filters.
- **Clear filters** unticks Free cancellation along with the other filters.

### Free cancellation badge

Properties that offer free cancellation are now easy to spot.

- A green **Free cancellation** badge appears on qualifying property cards in the search results.
- The same badge appears on the property details page, under the price.
- Properties without free cancellation show no badge.

## Improvements

- Performance improvements to search filters and booking summary.

## Unchanged in this release

- Log in, one-time code and log out.
- Search form, date formats and validation messages.
- Sorting options.
- Booking form, booking references, confirmation page and My bookings.

## Known issues

None.

## Upgrade notes

No action is needed. Demo data is stored per release in the browser. Use **Reset demo data** in the footer to start with a clean slate.
